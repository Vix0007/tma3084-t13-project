Tips

- Commit the **PDF** of each submitted version (and the editable .docx/.pptx if the team wants it
  versioned). Name files so the version is clear, e.g. `VanQ_SRS_v1.0.pdf`.
- Requirement IDs (FR-xx) in the SRS should match the GitHub issue titles, so each issue links
  back to a requirement. See `GITHUB_SETUP.md`.
- The empty `.gitkeep` files only exist so Git keeps the empty folders; delete one once real files
  are in its folder.
